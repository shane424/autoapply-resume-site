AutoApply Resume Assistant

Powered by your local AutoApply server

How it works:
Browse to any job posting → click the floating button → the extension sends the job description to your local AutoApply server, which tailors your resume using Claude AI and saves the PDF to your Documents folder.

Default: http://localhost:8000 — change only if you moved the port

Start the server:
uvicorn app.main:app --reload --port 8000
Run this from your project folder with the venv activated.
Tip: Include everything — summary, all experience, all skills, education. The server tailors it per job without removing real experience.

Open your AutoApply dashboard to browse scraped remote jobs, or jump straight to a job board. Once you're on a job page, click the floating button to tailor your resume.
